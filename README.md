# NIIGO

家庭のタスクを Google Sheets と Web 画面の両方から編集する Apps Script アプリです。1つのスプレッドシートを1つの Space として使います。

## 導入

1. 空の Google スプレッドシートを作成します。
2. そのシートの「拡張機能 → Apps Script」で、紐付けられたプロジェクトを開きます。
3. このリポジトリの `Code.js`、`Index.html`、`SheetSidebar.html`、`appsscript.json` をプロジェクトへ配置します。`clasp` を使う場合は `.clasp.json.example` を参考に、紐付けられたプロジェクトの ID を `.clasp.json` に設定してください。
4. シートを開き直し、「NIIGO → 初期設定」を一度実行して権限を承認します。メニューが見えない場合は Apps Script のエディタから `setup()` を実行してください。4タブ、見出し、ID列、入力規則、編集時のトリガーを作成します。
5. Web 画面を使う場合は、Apps Script の「デプロイ → 新しいデプロイ」でウェブアプリを選びます。実行ユーザーを「ウェブアプリにアクセスしているユーザー」、アクセス権を「Google アカウントを持つ全員」に設定します。利用者にはスプレッドシートの編集権限も付与してください。

Apps Script のプロジェクトはスプレッドシートに紐付ける必要があります。`setup()` を再実行すると入力規則とトリガーを更新します。既存データは消去しません。

ローカルで `npm test` を実行すると、列の移動、独自列、ラウンド終了、参照名の変更を確認できます。

## シートでの操作

`Tasks` の担当者には、メンバー名をカンマで区切って直接入力できます。複数選択の画面は「NIIGO → 担当者を選択」から開きます。対象のタスク行を選択してから使ってください。

ラウンドを終了するときは「NIIGO → ラウンドを終了」を使います。未完了のタスクごとに次のラウンドまたは Backlog を選択できます。`Rounds.status` を直接 `Closed` に変更した場合は元に戻し、この操作へ案内します。列を移動した後は「NIIGO → 入力規則を更新」を実行してください。

## 採用した設計

- セルには参照先の名前を表示し、セルのメモに `NIIGO:["id"]` 形式で ID を記録します。担当者は複数 ID を記録します。名前の重複は許さず、名称変更時は ID を手掛かりに表示名を更新します。メモを消した場合は、重複のない表示名から参照を復元します。
- ID は UUID です。Web 画面からの追加時と、Sheets で行を編集した時に付与します。欠損や重複を検出した場合は Web 画面の読み書きを止めます。コピーした行の ID は自動変更しません。
- Task の初期ステータスは `Todo`、Round は `Planned` です。Task の名前以外の項目と Round の日付は空欄を許します。日付を入力する場合は `YYYY-MM-DD` とし、Round の終了日は開始日以降にします。進行中の Round は1件までです。
- Web 画面で保存する際は、読み込んだ行の内容と保存直前の内容を照合します。食い違う場合は再読み込みを求めます。行と列は保存直前に ID と見出しから探し直します。
- ラウンド終了時は未完了 Task ごとに移動先を指定します。次の Round がない場合も Backlog を選べます。完了 Task と期限は変更しません。
- ID 列は初期状態で最右に置き、非表示にして編集時の警告を設定します。タブと必須見出しの名前は変更しないでください。独自列は保持します。

## 制限

編集トリガーは、Sheets の通常のセル編集で動作します。外部 API や別のスクリプトによる変更では動作しないため、その経路で行を追加した場合は ID や参照メモを別途整える必要があります。複数セルを同時に貼り付けてラウンドを `Closed` にする操作では、終了時の移動先選択を行えません。ラウンド終了メニューを使ってください。

Web 画面の削除、検索、並べ替え、絞り込みは実装していません。シートの共有権限は Google Sheets 側で管理します。
